# Local protocol contract

This document is the human-maintained interoperability contract for the server. The
reviewed machine schema is `crates/protocol/schema/protocol.json`.
`crates/protocol/build.rs` generates the exhaustive `RpcName` enum, route
category and compatibility class at compile time. Generated wire and registry
code may not define gameplay behavior; active behavior remains in explicit
domain handlers.

Static extraction is not allowed to silently win over captured wire evidence.
`crates/protocol/schema/verified_overrides.json` contains the small set of
value-free field and wrapper corrections proven by production captures. The
import tool applies those corrections explicitly and fails if an override no
longer resolves; it never imports response bodies, account values or game
resources.

## Transport

The client sends the original binary Thrift envelope as form data to:

`POST /{domain}/{rpc}/{locale}/`

The embedded release listens only on a random `127.0.0.1` port. Every request
must carry:

- `X-GGFM-Session`: a 256-bit capability generated by Patch for this process.
- `X-GGFM-Request-Seq`: a strictly increasing unsigned request sequence.
- `X-GGFM-Device-Time`: device Unix seconds at dispatch.
- `X-GGFM-UTC-Offset`: device offset from UTC in minutes.

The route RPC, Thrift message name, decoded call name and session identity must
agree. A mutation with an absent/stale sequence, a mismatched `U_seq`/`U_id`,
or a capability not belonging to the current process is rejected before a
business handler runs. Query handlers do not mutate state.

## Compatibility boundaries

The 127 recovered calls are a disjoint, exhaustive registry:

- 69 active calls have explicit query or command handlers. This includes six
  state-changing calls recovered from the tested Rust baseline and the
  production-captured `completeLog` telemetry call after the initial static
  call-site audit.
- 45 transport-only calls return the typed baseline-compatible response and cannot write.
- 13 DTO-only/dead-path calls return the typed baseline-compatible response and cannot
  write.

The three audited lists beside the schema are authoritative. Unknown RPC names
fail closed; they never fall through to a generic success response.

Production error envelopes omit the optional `Data` field. Successful
envelopes retain the RPC-specific list, map or struct shape. In particular,
`post/getPostTime` uses the common server-time wrapper and therefore places
`Data` at field 5; the similarly named tour DTO is not valid for that route.

## Mutation contract

Each command executes through the single SQLite writer. Eligibility checks,
currency deduction, ownership/progress changes, reward creation and the
mutation-ledger entry commit in one transaction. A success envelope is encoded
only after commit. Repeating an idempotency key returns the committed outcome
without issuing the reward again.

`userSave` is a partition merge. Missing Thrift fields mean “not carried” and
cannot erase a partition. Its request sequence is compared with the last
business transaction for that partition, so a late autosave cannot roll back a
purchase, claim, quest, equipment change, Gallery unlock or pass update.

Mail claim is one transaction: validate visibility, mark claimed, apply its one
reward and append the reward ledger. Memorial unique-item mail creation first
checks ownership and pending mail. One mail contains exactly one item.

## Time contract

Attendance, pass rotation, energy, Fever, skill cooldown and encore cooldown
derive from absolute timestamps plus the device offset. Server start does not
advance a day. The pass anchor is stored per USN; a manual season selection
sets that local-day anchor, and subsequent local days advance from it.

## Master data and distribution boundary

`master.sqlite` is generated by Patcher from the user's verified package and is
read-only at runtime. This repository contains schemas and transformation
rules, not original game rows, APKs, AssetBundles, DEX, metadata or captured
production configuration. Missing required master tables abort startup.

Recovered historical rankings, live-ops directories and probabilities that
cannot be established from the client are explicitly memorial compatibility
values, not claims about the former production service.

## Android ABI

The stable C ABI is declared in `include/ggfm_server.h`. Patch supplies the
private data directory, borrowed Android `AssetManager`, device time, UTC
offset and capability to `ggfm_server_start`. `ggfm_server_begin_login`
activates a pending slot only at a cold title login. `prepare_shutdown` flushes
WAL state; correctness does not depend on it because business RPCs commit
before returning.

`ggfm_server_policy_sha256` exports the exact embedded policy fingerprint.
Patch verifies it at bootstrap, and Patcher rejects a Server binary whose
fingerprint differs from the policy written into the APK.
